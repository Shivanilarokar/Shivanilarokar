### 🏗️ [Forge: Multi-Tenant Agent Platform](https://github.com/Shivanilarokar/AgentPlatformCapstone)
**Describe an agent in plain English, and Forge builds it.** It wires real MCP tool servers, **pauses for a human** before anything risky, scores the agent, and publishes it to a reviewed marketplace that other companies install with their own credentials.

- 🧩 Agents are **config, not code**: one runtime compiles them into multi-agent graphs
- ⏸️ Durable `interrupt()` approvals persisted in Postgres **that survive restarts**
- 🔐 Schema + role per tenant, **row-level security**, AES-256-GCM credential vault
- ☁️ Docker locally, **Cloud Run + Cloud SQL** in production · ✅ **266 tests**

### 🕵️ [Sentinel: Multi-Agent Fraud Analyst](https://github.com/Shivanilarokar/Sentinel-MultiagentFraudAnalyst)
**411 alerts. 276 accounts. A defensible verdict for every one.** A supervisor routes each case through four specialists (behaviour, context, network, disposition), each blind to the others' tools.

- 🧱 Tool-isolated specialists: **95.6%** of raw tool output never reaches the supervisor
- 📜 Policy-gate middleware: no write happens until the right policy is read
- 🙋 **Human approval** before blocking a card or escalating a case
- 🔎 3-layer citation validation against real rows · ✅ **76 offline tests**
